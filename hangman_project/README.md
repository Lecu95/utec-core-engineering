# Juego del Ahorcado en Python (Hangman Project)

Proyecto en Python que implementa el juego clasico del Ahorcado basado en consola de comandos.

## Estructura de Archivos

* `main.py`: Punto de entrada, bucle principal, interfaz ASCII y rejugabilidad.
* `game.py`: Clase `HangmanGame` con la logica de estado, errores y progreso.
* `utils.py`: Funciones de carga aleatoria de palabras desde archivo.
* `wordlist.txt`: Base de datos de palabras y frases por linea.
* `README.md`: Documentacion del proyecto.
